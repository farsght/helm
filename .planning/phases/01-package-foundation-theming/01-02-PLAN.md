From 01-PATTERNS.md — theme.css declaration order (Tailwind v4 declaration order matters):
  1. @custom-variant dark (&:is(.dark *));
  2. @source "../../src";  ← path relative to src/styles/theme.css; resolves to packages/ui/src
  3. @theme inline { ... }  ← MUST come before :root so token utility classes register before values
  4. :root { ... }
  5. .dark { ... }

From 01-PATTERNS.md — what NOT to include in theme.css:
  - @import "tailwindcss";  ← consumer owns this; adding it here causes Tailwind to process twice
  - Lines 4-10 of app/globals.css: standalone @theme { font-family, radius } block ← redundant with @theme inline; DROP
  - The @layer base { body { letter-spacing } } block ← consumer concern
  - The * { @apply border-border } and body { @apply ... } rules ← consumer concern

From 01-PATTERNS.md — tokens.ts export shape:
  export const tokens = { chart: ['var(--color-chart-1)', ..., 'var(--color-chart-5)'], color: { background, foreground, primary, muted, mutedFg, destructive, border } } as const
  export type TokenChart = typeof tokens.chart[number]
  export type TokenColor = keyof typeof tokens.color

Key: use var(--color-chart-N) NOT var(--chart-N) — the @theme inline block maps --color-chart-1 → var(--chart-1);
Recharts stroke/fill should reference the --color-* names (the Tailwind utility names).
